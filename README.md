# Metin3 — Grand2 referanslı yeni web tasarımı

Grand2 sitesinin tanıtım, indirme ve oyuncu erişimi yapısından esinlenen, Metin3 için hazırlanmış bağımsız web tasarım önizlemesi.

Statik site dosyaları dist/ içindedir. Tasarımda yer alan haber ve açıklamalar örnek içeriktir. Giriş ve kayıt için ayrı form ekranları vardır; gerçek hesap veya indirme servisine henüz bağlantı kurulmaz. Hesap ekranlarını ve sol alan görsellerini düzenlemek için HESAP_EKRANLARI.md dosyasına bakın.

Oyun projesinden ayrı hazırlanmıştır.
